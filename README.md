T-SQL QR Code Generator

A QR Code Generator implemented entirely in Microsoft SQL Server T-SQL.



Features

QR Code Versions 1-10

Reed-Solomon Error Correction

Automatic Mask Selection

SVG Generation

Colorized Logo Support
