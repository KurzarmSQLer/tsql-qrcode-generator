# Logo Placement Modes

## STRICT

Protected:

- Finder
- Separator
- Timing
- Dark Module
- Format Information
- Version Information
- Alignment Patterns

Recommended for maximum standards compliance.

## RELAXED

Protected:

- Finder
- Separator
- Timing
- Dark Module
- Format Information
- Version Information

Alignment Patterns may be covered by the logo.

Recommended for large branded QR codes when using ECC H.
